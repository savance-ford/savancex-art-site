# Experience mapping notes

## Reference patterns implemented

### Global navigation
- Thin black utility strip
- White sticky header
- Centered rounded wordmark
- Left-side primary navigation
- Right-side search, login, and cart controls
- Product/category mega-menu
- Responsive mobile menu drawer

### Homepage sequence
1. Full-bleed campaign hero with one primary CTA
2. Repeating free-shipping marquee
3. Centered featured-collection heading
4. Three-column product grid
5. Horizontal customer-review ticker
6. Urgent/restock collection section
7. Review statistics and recommendation proof
8. Large core-product catalog grid
9. Two-column brand-story section
10. Community/social image grid
11. Discount newsletter
12. Multi-column footer

### Catalog and collection pages
- Large page heading
- Category tabs
- Filter and sort controls
- Four-column desktop catalog
- Two-column mobile catalog
- Product sale and sold-out states
- Product review counts and price hierarchy

### Product detail page
- Two-column desktop image gallery and sticky information panel
- Product title, rating, compare-at price, and sale price
- Color and size options
- Size-guide access
- Add-to-bag action
- Fit-position meter
- Feature list
- Expandable shipping, warranty, care, and size information
- Recommendations and review content

### Commerce placeholders
- Cart drawer
- Full cart route
- Shipping-threshold progress
- Quantity management
- Search experience
- Account and order tracking forms
- Checkout UI without payment processing

## Original-content boundary

The implementation follows public interface patterns and interaction flow, but it deliberately uses a new brand identity, new copy, original SVG product mockups, and licensed placeholder photography. Replace placeholder assets and product data with materials you own before production use.
